# Saiful Islam - Developer Portfolio 🚀

Welcome to my personal portfolio website built with **React.js** and **Tailwind CSS**. This site showcases my projects, skills, and experiences as a front-end web developer.


## 🔗 Live Site

👉 [Visit Portfolio](https://saiful-protfolio.vercel.app/)

## 🛠️ Built With

- React.js
- TypeScript
- Tailwind CSS
- React Icons / Lucide Icons
- Vite
- EmailJS (for contact form)
- Custom Context for Theme Toggle (Light/Dark Mode)
- Responsive Design

## ✨ Features

- 🎨 Light and Dark mode toggle (with system preference support)
- 📱 Fully responsive layout for all devices
- 🧩 Projects section with smooth animations
- ✉️ Working contact form with EmailJS
- 🌍 Scroll navigation with active link highlights
- 🔍 Clean, modern UI and transitions
- ⚡ Fast loading with Vite
